# Noori Telegram Bot — Bilingual Dari / English

## زبان / Language
- در اولین `/start` کاربر زبان خود را انتخاب می‌کند: 🇦🇫 دری یا 🇬🇧 English.
- زبان انتخاب‌شده برای همان کاربر ذخیره می‌شود.
- `/LANGUAGE` یا `/language` برای تغییر زبان است.
- متن‌ها، دکمه‌ها، پاسخ‌های Callback، پنل ادمین، عضویت اجباری، کپچا، پرداخت، کیف پول، تیکت، آپلود و پیام‌های خطا از زبان انتخاب‌شده پیروی می‌کنند.
